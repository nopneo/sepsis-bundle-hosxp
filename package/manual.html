3สร้าง user ฐานข้อมูลแบบอ่านอย่างเดียว

ให้ผู้ดูแล HOSxP รันคำสั่งนี้บนเครื่องฐานข้อมูล (เปลี่ยน IP และรหัสผ่านเป็นของ รพ.) ระบบไม่เขียนข้อมูลใด ๆ ลง HOSxP

-- IP ของเครื่องที่จะติดตั้งระบบ เช่น 192.168.1.50 · ตั้งรหัสผ่านใหม่ที่คาดเดายาก
CREATE USER 'sepsis_ro'@'192.168.1.50' IDENTIFIED BY 'ตั้งรหัสผ่านเอง';
GRANT SELECT ON hos.* TO 'sepsis_ro'@'192.168.1.50';
FLUSH PRIVILEGES;
อย่าใช้ user ที่เขียนได้ (เช่น sa / root ของ HOSxP) — ถ้าเครื่องติดตั้งถูกเจาะ ข้อมูลใน HOSxP จะไม่ถูกแก้

ถ้าระบบติดตั้งบนเครื่องเดียวกับฐานข้อมูล ใช้ 'sepsis_ro'@'localhost' และ DB host 127.0.0.1

4ติดตั้งบน Linux

  1. คัดลอกไฟล์ zip ไปที่เครื่อง (เช่นใช้ WinSCP หรือคำสั่ง scp)
  2. เข้าเครื่องด้วย SSH แล้วแตกไฟล์และรันสคริปต์ติดตั้ง 
    unzip sepsis_bundle_v{{VERSION}}.zip
cd sepsis_bundle_v{{VERSION}}
sudo bash install.sh
    ต้องการพอร์ตอื่นที่ไม่ใช่ 5800 ให้รัน sudo PORT=5900 bash install.sh
  3. ตอบคำถาม: ชื่อโรงพยาบาล, DB host, port, ชื่อฐานข้อมูล (ปกติ hos), DB user และรหัสผ่าน (พิมพ์แล้วไม่แสดงบนจอ)
  4. รอสคริปต์ทำงานจนขึ้น ติดตั้งเสร็จแล้ว พร้อมลิงก์แดชบอร์ด

5ติดตั้งบน Windows

  1. ติดตั้ง Python 3.11 หรือ 3.12 จาก https://www.python.org/downloads/ — หน้าแรกของตัวติดตั้งติ๊ก "Add python.exe to PATH"
  2. แตกไฟล์ zip (คลิกขวา → Extract All…) ห้ามรันจากในไฟล์ zip โดยตรง
  3. ดับเบิลคลิก install_windows.bat → กด Yes เมื่อ Windows ขอสิทธิ์ Administrator
  4. ตอบคำถามเหมือนบน Linux แล้วรอจนขึ้น ติดตั้งเสร็จแล้ว

6ตรวจรหัสรายการของโรงพยาบาล

รหัส lab และรหัสยาใน HOSxP ต่างกันในแต่ละโรงพยาบาล สคริปต์ติดตั้งรัน setup_check.py --write ให้แล้ว ซึ่งค้นจากชื่อรายการ เลือกเฉพาะรายการที่มีการใช้จริงใน 1 ปี แล้วเขียนลง .env ต้องให้ทีมตรวจทานทุกครั้ง

รันตรวจซ้ำ

# Linux
cd /opt/sepsis_bundle && sudo -u sepsis .venv/bin/python setup_check.py
# Windows (PowerShell แบบ Administrator)
cd C:\sepsis_bundle; .venv\Scripts\python.exe setup_check.py

  IV fluid crystalloid 1000 ml (drugitems) → SEPSIS_IV_FLUID_ICODES
   *    1000187  ใช้  5306 ครั้ง  NSS INJ. 0.9 % , 1000 ML
   *    1000183  ใช้   104 ครั้ง  RLS-LACTATED RINGER 1000 ml.
ค่าใน .envใส่อะไรตรวจกับใคร
SEPSIS_LACTATE_LAB_ITEMSรหัส lab_items ของ Lactateห้อง lab
SEPSIS_HEMOCULTURE_LAB_ITEMSรหัส lab_items ของ Hemoculture ถ้า รพ. สั่งผ่านระบบ labห้อง lab
SEPSIS_HEMOCULTURE_ICODESicode ใน nondrugitems ถ้า รพ. สั่ง Hemoculture เป็นรายการค่าบริการห้อง lab / การเงิน
SEPSIS_IV_FLUID_ICODESicode ของ NSS / RLS / Acetar ถุง 1000 ml (ไม่ใส่ NSS 100 ml ที่ใช้ผสมยา)ห้องยา
SEPSIS_NOREPINEPHRINE_ICODESicode ของ Norepinephrine (Levophed)ห้องยา
SEPSIS_DOPAMINE_ICODESicode ของ Dopamine (ใช้เตือนเมื่อใช้ก่อน NE)ห้องยา
SEPSIS_ICU_WARDSรหัส ward ที่เป็น ICU (ถ้ามี) — ใส่เองใน .env ไม่มีในการค้นอัตโนมัติIT / หอผู้ป่วย

Hemoculture ใส่ได้ทั้งสองแบบพร้อมกัน ระบบใช้เวลาที่เร็วที่สุด · คั่นหลายรหัสด้วยจุลภาค เช่น 1000187,1000183

ยาปฏิชีวนะ ไม่ต้องใส่รหัส — ระบบใช้ยาที่ติ๊ก antibiotic = 'Y' ในทะเบียนยา (drugitems) ของ HOSxP ถ้า setup_check เตือนว่าไม่มี ให้ห้องยาตั้งค่าใน HOSxP ก่อน

setup_check ยังแสดงตารางรหัสสถานะจำหน่าย (ovstost, er_dch_type) ว่าแต่ละรหัสนับเป็น Refer / เสียชีวิต / กลับบ้าน ฯลฯ ถ้า รพ. ตั้งรหัสต่างจากมาตรฐาน แก้ได้ใน .env (หัวข้อ 15)

แก้ .env แล้วต้อง restart หน้าเว็บ (หัวข้อ 17) — งานแจ้งเตือนอ่านค่าใหม่เองในรอบถัดไป

7ตั้งค่าแจ้งเตือน MOPH Notify

MOPH Notify (หมอพร้อม) ส่งข้อความเข้ากลุ่ม LINE ของหน่วยบริการโดยไม่มีค่าใช้จ่าย ทำครั้งเดียว:

  1. สร้างกลุ่ม LINE แล้วตั้งชื่อให้ลงท้ายด้วย HC + รหัสหน่วยบริการ 5 หลัก เช่น Sepsis ER HC12345 — ต้องตั้งชื่อก่อนเชิญหมอพร้อม
  2. เชิญบัญชี LINE "หมอพร้อม" เข้ากลุ่ม
  3. Admin หน่วยบริการเข้า CMS MOPH Notify แล้วอนุมัติกลุ่ม
  4. ดู Client_ID และ Secret ของกลุ่มในเมนูกลุ่มบอท
  5. เปิด http://<IP เครื่อง>:5800/settings (หรือปุ่ม "⚙️ ตั้งค่าแจ้งเตือน" บนแดชบอร์ด) แล้วกรอกรหัส — ถ้าตั้งรหัสดู HN/AN ไว้ (หัวข้อ 9) ใช้รหัสเดียวกัน ระบบถามทุกครั้งที่เข้าหน้านี้ · ถ้าไม่ได้ตั้ง ใช้รหัสผ่าน SEPSIS_SETTINGS_PASSWORD จาก .env (ชื่อผู้ใช้อะไรก็ได้ · Linux: install.sh สร้างให้ · ถ้าไม่ตั้งทั้งสองค่า เปิดได้เฉพาะบนเครื่องเซิร์ฟเวอร์ที่ http://127.0.0.1:5800/settings) กรอก Client Key และ Secret Key แล้วกด บันทึก + ทดสอบส่ง

ถ้าสำเร็จ กลุ่ม LINE จะได้การ์ดทดสอบ 2 ใบ (ข้อมูลสมมติ) ค่าที่บันทึกเก็บใน data/moph_settings.json ไม่ต้อง restart

หน้าตั้งค่าแจ้งเตือน
ทางเลือก: ถ้าไม่ใช้ MOPH Notify ระบบส่งเป็นข้อความธรรมดาผ่าน LINE Messaging API ได้ (ต้องมี LINE Official Account เอง) โดยใส่ LINE_CHANNEL_ACCESS_TOKEN และ LINE_TO ใน .env · LINE Notify เดิมปิดบริการแล้วตั้งแต่ มี.ค. 2568

    Urine outputบันทึกพยาบาล (ER หรือ KIPS หอผู้ป่วย) เช่น retained foley, สวนปัสสาวะคาสาย, I/Oมีบันทึก (ไม่มีเวลา)

    บันทึกพยาบาลหอผู้ป่วยจาก KIPS (IPD paperless)

    ถ้า รพ. ใช้ KIPS (มีตาราง kips_ipd_nurse_focus_detail) ระบบอ่านบันทึก focus charting ของ AN นั้นเพิ่ม สำหรับยาปฏิชีวนะ, IV fluid, O2 และ Urine output — ช่วยเคสที่แพทย์ลงรหัส sepsis หลัง admit และการดูแลชั่วโมงแรกเกิดบนหอ

    • มีเวลาในข้อความ เช่น - Cef-3 2 gm iv drip at 12.20 น. → นับเป็นเวลาให้จริง (แหล่ง "พยาบาลบันทึกเวลาให้ (KIPS หอผู้ป่วย)") ถ้ามีทั้ง ER และ KIPS ใช้เวลาที่เร็วกว่า
    • ไม่มีเวลา เช่น - ให้ยา Cef-3 2 gm v OD → ใช้เวลาที่บันทึกใน KIPS เป็นเวลาที่ "ให้แล้วไม่ช้ากว่านี้" เฉพาะเมื่อเร็วกว่าเวลาสั่งยา (แหล่ง "พยาบาลบันทึกใน KIPS (ใช้เวลาบันทึก)")

    การเตือนเคสใหม่ไม่ขึ้นกับ KIPS — ระบบจับเคสจากรหัส ICD10 ที่แพทย์ลง ไม่ว่าพยาบาลจะบันทึกที่ไหน · ปิดการอ่าน KIPS ได้ด้วย SEPSIS_KIPS_NOTES=0

    "ครบ 4 ข้อ" นับเฉพาะ Lactate, Hemoculture, ยาปฏิชีวนะ และ IV fluid · ออกซิเจนและ Urine output แสดงผลประกอบ ถ้าไม่พบบันทึกจะขึ้น "ยืนยันเอง"

    เวลาสั่ง ≠ เวลาให้จริง — HOSxP ไม่มีตารางบันทึกการให้ยาที่เชื่อถือได้ (ipd_mar เป็นตารางคำสั่ง) ระบบจึงใช้เวลาที่พยาบาลเขียนในบันทึกก่อน ถ้าไม่มีจึงใช้เวลาสั่ง ซึ่งอาจเร็วกว่าเวลาให้จริง หน้าแดชบอร์ดบอกแหล่งของเวลาทุกข้อ

    19ข้อจำกัดที่ควรรู้

    1. เวลาให้จริงมีเฉพาะที่พยาบาลเขียนไว้ในบันทึก ER — ที่เหลือเป็นเวลาสั่งซึ่งอาจเร็วกว่าเวลาให้จริง
    2. ตัวอ่านบันทึกพยาบาลพัฒนาจากรูปแบบการเขียนของ รพ.วังน้ำเขียว — รพ. อื่นควรทวนผลกับเวชระเบียนช่วงแรก และปรับรูปแบบการบันทึกตามหัวข้อ 14
    3. ระบบเห็นเคสเมื่อมีการลง ICD10 sepsis เท่านั้น — เคสที่ยังไม่ลงรหัสจะไม่ถูกแจ้ง และไม่ใช่เครื่องมือคัดกรอง (screening) sepsis
    4. ออกซิเจนและ Urine output ไม่มีในช่องข้อมูลโครงสร้างของ HOSxP จึงอ่านจากบันทึกพยาบาล ถ้าไม่พบต้องยืนยันเอง
    5. HOSxP รุ่นเก่าที่ไม่มีช่องเวลา sepsis/triage ใน er_regist ยังใช้ได้ โดยใช้เวลาเข้า ER แทน
    6. ตัวชี้วัด SSC 2026: ปริมาณสารน้ำนับเฉพาะ load ที่พยาบาลเขียนไว้ (ไม่ใช่ I/O จริง) · NEWS2 ที่คำนวณเองอาจต่ำกว่าจริงถ้าไม่มีข้อมูลความรู้สึกตัว · ยังไม่ได้ติดตามการประเมินซ้ำหลังให้สารน้ำ การปรับยาตามผลเพาะเชื้อ (de-escalation) และ MAP เป้าหมาย
    7. ผลในระบบใช้เพื่อพัฒนาคุณภาพ ไม่ใช่หลักฐานทางเวชระเบียน — การตัดสินทางคลินิกเป็นของแพทย์และพยาบาลผู้ดูแล
