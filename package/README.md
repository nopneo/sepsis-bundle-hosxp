# Sepsis Six Bundle — ระบบติดตามและแจ้งเตือนผู้ป่วย Sepsis จาก HOSxP

เวอร์ชัน {{VERSION}} · พัฒนาโดย โรงพยาบาลวังน้ำเขียว จ.นครราชสีมา

ติดต่อ: นายเผด็จชัย สิงหล โรงพยาบาลวังน้ำเขียว โทร 086-257-4817

ระบบดึงเคส sepsis (ICD10 A40.x, A41.x, R57.2) จาก HOSxP ทุก 15 นาที ตรวจว่าทำ Sepsis Six Bundle
ครบภายใน 1 ชม. นับจากมาถึง ER หรือไม่ แสดงบนแดชบอร์ดในวง LAN และแจ้งเตือนเข้ากลุ่ม LINE ผ่าน MOPH Notify

รุ่น 1.1: เพิ่มตัวชี้วัดตาม Surviving Sepsis Campaign 2026 — แยกเคส shock + เป้ายาปฏิชีวนะ 1/3 ชม., ค่า Lactate และการวัดซ้ำ,
สารน้ำเทียบ 30 mL/kg + balanced crystalloid, norepinephrine/dopamine, refer/ICU ภายใน 6 ชม., NEWS2 แรกรับ,
แนวโน้มรายเดือน และแผงความครบถ้วนของข้อมูลใน HOSxP

รุ่น 1.2: เพิ่ม `hosxp_alert/` — หน้าต่างเตือน "สงสัย Sepsis" ในหน้าซักประวัติ HOSxP (SOS > 3 + ไข้/ตัวเย็น)
แยกหน้าตาจุดคัดกรอง (ส่ง ER ทันที) กับ ER (เริ่ม Bundle + เวลาเป้าหมาย) พร้อมตัวติดตั้งที่สำรองและย้อนกลับได้ — ดู `hosxp_alert/README.md`

**อ่านคู่มือฉบับเต็มใน `คู่มือ-Sepsis-Six-Bundle.pdf`**

## ติดตั้งเร็ว

1. ให้ผู้ดูแล HOSxP สร้าง user แบบอ่านอย่างเดียว:
   ```sql
   CREATE USER 'sepsis_ro'@'<IP เครื่องติดตั้ง>' IDENTIFIED BY '<รหัสผ่าน>';
   GRANT SELECT ON hos.* TO 'sepsis_ro'@'<IP เครื่องติดตั้ง>';
   ```
2. ติดตั้ง (ต้องมี Python 3.9+ และออกอินเทอร์เน็ตไป pypi.org ได้)
   - **Linux:** `sudo bash install.sh`
   - **Windows:** ดับเบิลคลิก `install_windows.bat`
3. ตรวจรหัส lab/ยาที่สคริปต์เติมให้ใน `.env` กับห้อง lab/ห้องยา (`python setup_check.py`)
4. เปิด `http://<IP เครื่อง>:5800/settings` กรอก Client Key / Secret Key ของกลุ่ม MOPH Notify แล้วกดทดสอบส่ง
   — หน้านี้ถามรหัส `SEPSIS_SETTINGS_PASSWORD` ใน `.env` (Linux: `install.sh` สร้างให้ · คนละรหัสกับรหัสดู HN/AN)
   ถ้าไม่ตั้ง เปิดได้เฉพาะบนเครื่องเซิร์ฟเวอร์ที่ `http://127.0.0.1:5800/settings`
5. เปลี่ยนโลโก้ที่ `static/logo.png` (ไม่บังคับ)

## สำคัญ

- **ห้ามเปิดแดชบอร์ดออกอินเทอร์เน็ต** — มีข้อมูลผู้ป่วยและไม่มีระบบล็อกอิน
- ห้ามส่งไฟล์ `.env` และโฟลเดอร์ `data/` ให้ผู้อื่น (มีรหัสผ่านฐานข้อมูลและ key ของกลุ่ม LINE)
- เวลาที่ระบบใช้คือเวลาที่พยาบาลบันทึกไว้ใน HPI ของ ER ก่อน ถ้าไม่มีจะใช้เวลาสั่ง ควรทวนผลกับเวชระเบียนช่วงแรก
